# Google Apps Script 설치 안내

1. Apps Script 새 프로젝트를 만듭니다.
2. `Code.gs` 내용을 Apps Script 편집기의 `Code.gs`에 붙여 넣습니다.
3. 프로젝트 설정에서 `appsscript.json` 표시를 켠 뒤, 이 폴더의 `appsscript.json` 내용으로 바꿉니다.
4. `setupKioskSpreadsheet()` 함수를 선택하고 실행합니다.
5. 권한 승인 화면에서 본인 계정으로 승인합니다.
6. 배포 > 새 배포 > 웹 앱을 선택합니다.
7. 실행 사용자는 `나`, 액세스 권한은 학교 정책에 맞게 `모든 사용자` 또는 `링크가 있는 모든 사용자`로 설정합니다.
8. 배포 후 `/exec`로 끝나는 웹앱 URL을 복사해 프런트엔드의 `VITE_KIOSK_API_URL` 값으로 사용합니다.

포인트 순위 응답에는 `number`, `name`, `active`, `total_points`, `rank`를 바탕으로 만든 `rank`, `displayName`, `totalPoints`만 포함됩니다. `password_code`와 아바타 관련 열은 API 응답에 넣지 않습니다.

## 하단 기초시간표·월간 식단표 (배포 대기)

상단의 오늘 시간표(`시간표` 탭)와 오늘 급식(`식단표` 탭)은 그대로 유지됩니다.
하단은 학사 일정 → 디데이 → 시간표 → 식단표 순서이며, 별도 데이터로 표시됩니다.

- `기초시간표`: A1:F1 = 교시, 월, 화, 수, 목, 금. A2부터 교시, B:F에 과목을 입력합니다. 비어 있는 요일은 —로 표시하며, 과목이 모두 비어 있는 교시는 생략합니다.
- `식단표 이미지`: A1 = 제목, B1 = 이미지. A2에 예: 2026년 10월 식단표, B2에 **삽입 → 이미지 → 셀 내 이미지**로 이미지를 넣습니다. `=IMAGE("https://...")` 또는 직접 열리는 이미지 URL도 지원합니다. 셀 위에 띄운 이미지는 지원하지 않습니다. IMAGE 수식의 URL은 문자열로 직접 지정하세요.
- 이미지 탐색 범위는 A1:D10이며, 첫 번째 이미지를 표시합니다. 월별 이미지 교체는 기존 이미지를 바꾸는 방식으로 합니다.
- Apps Script의 `setupOverviewSheets()`는 비어 있는 두 탭만 초기화합니다. 기존 데이터가 있는 탭은 덮어쓰지 않습니다.
- 셀 이미지의 Google URL은 잠시 후 만료될 수 있어 앱의 기존 1분 갱신으로 새 URL을 읽습니다. 오프라인에서는 시간표 캐시는 표시할 수 있으나 이미지 재표시는 보장되지 않습니다.

배포할 때는 수정된 Code.gs를 적용하고 Apps Script 기존 웹앱의 버전을 업데이트한 뒤 프런트엔드를 배포해야 합니다. 이번 수정에서는 두 배포 모두 실행하지 않습니다.
